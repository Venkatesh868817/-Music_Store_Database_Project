# 📊  Music Store Database Project

## 📌 Overview

This project is based on a **Music Store Database**, designed to manage and analyze data related to customers, albums, artists, tracks, invoices, and playlists.
It demonstrates how SQL can be used to extract meaningful insights from real-world structured data.

## 🗂️ Database Description

The database represents a digital music store where:

* Customers purchase music tracks
* Artists create albums
* Albums contain multiple tracks
* Invoices store purchase details
* Playlists organize tracks

## 🧩 Main Tables

* **Customers** → Stores customer details
* **Artists** → Information about music artists
* **Albums** → Albums created by artists
* **Tracks** → Individual songs with pricing and duration
* **Invoices** → Customer purchase records
* **Invoice_Items** → Tracks included in each purchase
* **Genres** → Music categories
* **Playlists & Playlist_Track** → Track collections

## 🚀 Features

* Query customer purchasing behavior
* Analyze sales and revenue
* Explore relationships between artists, albums, and tracks
* Identify popular genres and tracks
* Perform real-world business analysis using SQL

## 📚 Concepts Covered

* Basic SQL (SELECT, WHERE, ORDER BY)
* Aggregations (COUNT, SUM, AVG)
* JOINs (INNER JOIN, LEFT JOIN)
* GROUP BY & HAVING
* Subqueries and nested queries
* Data analysis using SQL

## ▶️ How to Use

1. Open SQLite (DB Browser or CLI)
2. Load the music store database
3. Run queries from the `.sql` file
4. Analyze outputs and modify queries

## 🎯 Learning Outcomes

* Understanding relational database structure
* Writing efficient SQL queries
* Performing business data analysis
* Gaining hands-on experience with real datasets
